DECISION A7 — ADDITIONAL BINDING CLARIFICATIONS
A7-C1 — PERMISSIVE / INSUFFICIENT TRIGGER BOUNDARY
Establish the following binding distinction:

Mandatory: the change materially affects the documented interpretation foundation.
Permissive: the change is relevant to the concept or interpretation, provides some substantive basis for possible reconsideration, and does not materially affect the documented foundation.
Insufficient: the event provides no substantive basis for reconsideration.
Clarify explicitly:

Relevance to the concept alone is not sufficient to create a Permissive trigger.
A Permissive trigger must provide some new substantive basis for possible reconsideration, however limited.
A change that is nominally relevant but contains no new information, reasoning, claim, contextual implication, support-landscape change, or substantive finding is Insufficient.
Relevant non-foundational changes that satisfy the Permissive threshold must be acknowledged in the research record, but reconsideration is not required.
This clarification supersedes any A7 wording that implies:
“relevant to the concept but non-foundational → automatically Permissive.”
Include the corrected Step 2 decision rule:

If the change materially affects the documented interpretation foundation → Mandatory.
If the change does not materially affect the documented foundation but is relevant and provides some substantive basis for possible reconsideration → Permissive.
If the event provides no substantive basis for reconsideration → Insufficient.
A7-C2 — DUPLICATION VS. INDEPENDENT CORROBORATION
Establish the following binding distinction:

Exact or substantively redundant duplication:

A claim repeats content already fully represented in the available claim landscape.
It adds no new information, reasoning, contextual implication, or meaningful change to the support landscape.
Trigger classification: Insufficient.
Independent corroboration:

A distinct source independently reaches or supports the same conclusion.
This changes the support landscape by adding independent convergence.
Trigger classification: Permissive, unless the change materially affects the documented interpretation foundation, in which case the general A7 framework determines whether it is Mandatory.
Relevant non-foundational extension:

A new claim adds substantive information relevant to the concept without materially affecting the documented interpretation foundation.
Trigger classification: Permissive.
Correct former A7 Test 2 accordingly.

Important semantic constraint:
Do not treat “separate source” alone as sufficient for independent corroboration. The support must be genuinely independent rather than derivative, copied, transcribed, or otherwise non-independent. Do not create a full independence-assessment procedure; preserve this only as a semantic distinction.
