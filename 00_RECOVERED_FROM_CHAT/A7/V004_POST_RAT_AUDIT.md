Post-Ratification Semantic Consistency Verification — Decision A7
A7-C1 — PERMISSIVE / INSUFFICIENT TRIGGER BOUNDARY
The following binding distinction supersedes any A7 wording that implies "relevant to the concept but non-foundational → automatically Permissive."

Corrected Three-Category Definitions
Mandatory: The change materially affects the documented interpretation foundation.

Permissive: The change is relevant to the concept or interpretation, provides some substantive basis for possible reconsideration, and does not materially affect the documented foundation. The researcher may reconsider but is not required to. Changes meeting this threshold must be acknowledged in the research record.

Insufficient: The event provides no substantive basis for reconsideration. This includes preference shifts, silent substitutions, downstream departures without substantive findings, and changes that are nominally relevant to the concept but contain no new information, reasoning, claim, contextual implication, support-landscape change, or substantive finding not already fully accounted for in the available claim landscape.

Binding Clarifications
Relevance to the concept alone is not sufficient to create a Permissive trigger.

A Permissive trigger must provide some new substantive basis for possible reconsideration, however limited.

A change that is nominally relevant but contains no new information, reasoning, claim, contextual implication, support-landscape change, or substantive finding is Insufficient.

Relevant non-foundational changes that satisfy the Permissive threshold must be acknowledged in the research record. Reconsideration is not required.

This clarification supersedes any A7 wording that implies: "relevant to the concept but non-foundational → automatically Permissive."

Corrected Step 2 Decision Rule
If the change materially affects the documented interpretation foundation → Mandatory
If the change does not materially affect the documented foundation but is relevant and provides some substantive basis for possible reconsideration → Permissive
If the event provides no substantive basis for reconsideration → Insufficient
A7-C2 — DUPLICATION VS. INDEPENDENT CORROBORATION
The following binding distinction corrects former A7 Test 2, which classified all duplicate supporting claims as Permissive without distinguishing substantive duplication types.

Binding Distinctions
1. Exact or substantively redundant duplication

A claim repeats content already fully represented in the available claim landscape. It adds no new information, reasoning, contextual implication, or meaningful change to the support landscape.

Trigger classification: Insufficient.

2. Independent corroboration

A distinct source independently reaches or supports the same conclusion. This changes the support landscape by adding independent convergence, which is research-relevant even when the conclusion is the same.

Trigger classification: Permissive, unless the independent corroboration materially affects the documented interpretation foundation, in which case the general A7 Trigger Determination Framework (Step 2) determines whether it is Mandatory.

Semantic constraint: A separate source alone is not sufficient to establish independent corroboration. The support must be genuinely independent rather than derivative, copied, transcribed, or otherwise non-independent in origin. No full independence-assessment procedure is defined here; this remains a semantic distinction for researcher judgment.

3. Relevant non-foundational extension

A new claim adds substantive information relevant to the concept without materially affecting the documented interpretation foundation.

Trigger classification: Permissive.

Corrected Test 2
Concept: Fair Value Gap
New claim: A second source states the same three-candle imbalance definition already fully present in the available claim landscape from Source A.

Sub-case determination:

If the second source is derivative, transcribed, or copied from Source A: Insufficient — exact/substantively redundant duplication; no new information, no support-landscape change.
If the second source independently developed or arrived at the same conclusion: Permissive — independent corroboration; the support landscape changes by adding convergent independent evidence, which is research-relevant.
In either case, the documented interpretation foundation is not materially affected; no Mandatory trigger arises.
